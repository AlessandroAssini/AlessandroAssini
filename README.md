## Featured projects

### 🛡️ ASPIS

A personal fork of **ASPIS — Automatic Software-based Protection and Integrity Suite**, an LLVM plugin that operates on Intermediate Representation to harden software against Single-Event Upsets.

The project applies software-based protection techniques through a sequence of LLVM compiler passes.

**Technologies:** C++, LLVM, CMake, compiler passes

> This repository is a fork of the original project developed by HEAPLab.

[View my fork](https://github.com/AlessandroAssini/ASPIS) ·
[View the original project](https://github.com/HEAPLab/ASPIS)

### 🎲 MyShelfie

A Java client-server implementation of the *My Shelfie* board game, developed for the Software Engineering course at Politecnico di Milano.

Main features:

- MVC architecture
- Socket and Java RMI communication
- Command-line and graphical interfaces
- Integrated chat
- Concurrent multiplayer games

**Technologies:** Java, Maven, Socket, RMI, JavaFX

### ⚙️ VHDL Memory Router

A digital hardware module that reads a serialized input sequence, selects one of four output channels and retrieves a value from memory using a 16-bit address.

Main features:

- VHDL hardware design
- Finite-state machine
- 16-bit memory addressing
- Four output channels
- Simulation and synthesis

**Technologies:** VHDL, digital logic design

[View repository](https://github.com/AlessandroAssini/Project-Reti-Logiche-2023)
